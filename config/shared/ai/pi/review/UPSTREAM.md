# Provenance

`rubric.md` adapts the review criteria from [earendil-works/pi-review](https://github.com/earendil-works/pi-review/blob/f1de050504936046c0f85b21fec0e0a93ef394eb/review.ts),
commit `f1de050504936046c0f85b21fec0e0a93ef394eb` (MIT; license retained here).

Adaptations follow the dotfiles review policy: findings only; no style-only
findings, automatic verdict/merge approval, or authority granted to reviewed files.
The tool implementation is local and uses Pi's SDK, not upstream session navigation.
No pi-review runtime dependency is installed.
